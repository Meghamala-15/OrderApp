# Mega Orders 🍔🍕

Mega Orders is a simple and responsive food ordering web application built using HTML, CSS, and JavaScript. Users can browse food items, add them to the cart, remove items, and generate a receipt during checkout.

---

## 🚀 Features

- Responsive food menu layout
- Add to Cart functionality
- Remove items from cart
- Dynamic total price calculation
- Checkout receipt popup
- Modern UI design with animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
